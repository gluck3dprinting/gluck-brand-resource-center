반영 절차

저장 후 아래 3단계면 끝
  1. 실물 파일 배치
    등록 폼에 드롭한 파일을 brand-assets/logo/(가이드 보드는 guideline/)에 넣습니다.
  2. assets.js 저장
    상단 변경사항 저장 — 브라우저가 파일 위치를 물으면 저장소의 brand-assets/assets.js를 선택해 덮어씁니다. (지원하지 않는 브라우저는 다운로드 후 교체)
  3. git push
    푸시하면 GitHub Pages에 1~2분 내 자동 반영됩니다. ZIP 패키지 갱신은 선택입니다.
    git add -A && git commit -m "brand assets 갱신" && git push
