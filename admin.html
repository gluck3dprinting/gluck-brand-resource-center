발행 방법

둘 중 하나
A · GitHub에 발행 (권장)자동
  1. 사이드바 연결 설정에서 GitHub 토큰 1회 등록
  2. 자산 등록·수정 후 우상단 GitHub에 발행 (또는 Ctrl+S)
  3. 업로드 파일 · assets.js · ZIP 패키지가 한 커밋으로 올라가고 1~2분 뒤 공개 페이지에 반영
B · 파일 내려받아 직접 반영수동
  1. 우상단 assets.js 다운로드 → 저장소 brand-assets/assets.js 교체
  2. 등록 폼에 드롭한 실물 파일을 brand-assets/logo/(보드는 guideline/)에 복사
  3. git commit · push — 삭제한 자산의 실물 파일은 두 방법 모두 저장소에 남습니다

GitHub 연결

발행에 쓰는 토큰은 이 브라우저에만 저장되며 어디에도 전송되지 않습니다 (GitHub API 호출에만 사용).

토큰 만들기 (1회 · 약 1분)
  1. github.com › Settings › Developer settings › Fine-grained tokens › Generate (gluck3dprinting 계정)
  2. Repository access → Only select repositories → gluck-brand-resource-center
  3. Permissions → Repository permissions → Contents: Read and write (Pages: Read는 선택)
  4. Generate 후 표시되는 github_pat_… 값을 아래에 붙여 넣기
